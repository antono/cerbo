## MODIFIED Requirements

### Requirement: Replace old switcher
The old inline vault switcher MUST no longer be shown. The sidebar SHALL have no vault header; the vault menu in the window toolbar SHALL be the only on-screen entry point to the selector.

#### Scenario: Sidebar header
- **WHEN** a vault is open
- **THEN** the toolbar SHALL show the vault name as a button that opens the selector
- **THEN** the sidebar SHALL show no vault name, no header and no inline vault list
